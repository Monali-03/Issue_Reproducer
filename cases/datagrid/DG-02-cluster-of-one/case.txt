## Topology
Three RHDG 8.5 server nodes intended to form one cluster. Hot Rod and REST clients both
connect. The nodes are on one subnet; the security team disabled multicast on it.

## Configuration
Shipped infinispan.xml with the default jgroups stack. See
configs/infinispan-jgroups.snippet.xml. No JGroups stack was customised.

## Steps to reproduce
1. Start all three servers.
2. Check the cluster view via /rest/v2/cluster or the console.

## Expected behavior
One cluster with 3 members.

## Actual behavior
Each node reports a cluster of one — three separate clusters. Clients see different data
depending on which node they hit, and a cache created on one node is absent on the others.
